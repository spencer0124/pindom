# 장소 누끼로 함께 촬영하기

> 관데공 장소를 찾고, 투명 PNG 누끼와 사진을 합쳐 티켓으로 남기는 사용자·팀 가이드입니다.

## 준비하기

누끼 기능을 지원하는 앱으로 업데이트하고 위치·카메라 권한을 허용합니다. 지도에서 최애를 **관데공**으로 선택한 뒤 원하는 장소를 엽니다. 사진을 불러오려면 인터넷 연결이 필요합니다.

지도 핀은 API로 확인한 **장소의 대표 좌표**입니다. 제공 사진을 찍은 정확한 위치는 아니므로 실제 촬영 지점과 다를 수 있습니다. 이번 등록 장소의 GPS 인증 반경은 **50m**이며, 장소 상세의 인증 조건을 기준으로 확인합니다. 이동속도 검증과 하루 1회 조건도 적용됩니다.

## 촬영하고 티켓 만들기

1. 장소 상세에서 배경 사진과 제공자 초성, 사진 출처를 확인합니다.
2. **GPS 인증하기**를 눌러 인증을 마치고 촬영 화면으로 이동합니다.
3. 화면에 나타난 누끼를 드래그해 옮깁니다. **누끼 크기** 슬라이더로 크기를 조절하고, **좌우 반전**으로 방향을 바꿉니다.
4. **누끼 켜짐 / 누끼 꺼짐**으로 표시 여부를 선택합니다. **초기화**는 누끼의 위치·크기·방향을 처음 상태로 돌립니다.
5. 셔터를 누릅니다. 실제 카메라 모드에서는 촬영한 사진을 고정한 뒤, 배치한 PNG 누끼를 합쳐 한 장의 사진으로 저장합니다.
6. 사진 편집 화면에서 결과를 확인하고 필요한 편집을 합니다. **다음**을 눌러 공개 범위를 선택한 뒤 기존 티켓 발행 흐름을 완료합니다.

누끼는 촬영할 때 사진에 합쳐집니다. 편집 화면에서 누끼만 다시 옮길 수는 없으므로 구도를 바꾸려면 **재촬영**을 누릅니다. 누끼를 끈 채 촬영하면 실제 사진만 편집 화면으로 전달됩니다.

## 등록 사진 확인하기

2026-09-19 등록분은 장소 23곳과 투명 PNG 누끼 23개입니다. 배경은 사용자 제공 사진 21장, 대체 대표 사진 1장, 미제공 1곳으로 구성됩니다. 현재 목록과 반경의 원본은 [관데공 카탈로그](../../src/mocks/gwandegong-catalog.json)에서 확인합니다.

| 항목 | 표시와 처리 |
| --- | --- |
| 제공자 | 모든 이름은 `ㅇㅎㅈ`, `ㅈㅅㅇ`, `ㅇㅈㅇ`, `ㄱㅁㅈ`처럼 한글 초성으로만 표시합니다. 실명을 추가하지 않습니다. |
| 몰리또 대학로점 | 원본 배경 사진이 아직 없습니다. 상세에는 **장소 사진 준비 중**을 표시하며, 인물 누끼는 제공됩니다. |
| 아르떼뮤지엄 부산 | 촬영 당시 배경 대신 장소 외관 대표 사진을 사용합니다. **한국관광공사(TourAPI) · 공공누리 제1유형** 출처와 원문 링크를 장소 상세에 표시합니다. |

## 반영 범위와 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 기존 앱에 새 장소가 보이지 않음 | 지도·최애 목록에서 데이터를 다시 불러오거나 앱을 다시 엽니다. 백엔드에 등록한 핀·기본 장소 사진은 데이터 재조회로 반영됩니다. |
| 장소는 보이는데 누끼 조작부가 없음 | 누끼 촬영 기능이 포함된 앱으로 업데이트합니다. 데이터 재조회만으로 이전 앱에 새 촬영 기능이 생기지는 않습니다. |
| 누끼를 불러오는 중이거나 로딩 실패 | 인터넷 연결을 확인하고 다시 시도합니다. 누끼 없이 촬영하려면 **누끼 꺼짐**으로 전환합니다. |
| 카메라가 열리지 않음 | 위치 인증을 마쳤는지 확인하고 기기 설정에서 카메라 권한을 허용한 뒤 촬영 화면을 다시 엽니다. |
| **샘플 사진으로 촬영 연습 중** 표시 | 개발용 모의 촬영입니다. 장소 사진으로 편집 흐름을 확인할 수 있지만 실제 카메라 촬영 결과는 아닙니다. |

## 팀 검증 상태

2026-09-20 기준 타입 검사·린트·테스트 13개와 iOS·Android Hermes 번들 내보내기를 통과했습니다. iPhone 17 Pro Simulator에서 제공 배경과 투명 누끼의 표시, 접근성 동작을 통한 위치·크기 조절, 좌우 반전·켜기/끄기, 1200×1600 합성 JPEG 저장, 편집 화면과 티켓 미리보기까지의 전달, 비공개 모의 티켓 발행을 확인했습니다. iOS 캡처 경로를 `file://` URL로 정규화해 편집기에서 읽도록 처리했습니다.

시뮬레이터 검증은 개발 모의 촬영입니다. 실제 기기의 카메라 촬영, 손가락 드래그, 렌즈별 구도 유지와 Android 기기에서의 합성 저장은 별도 확인이 필요합니다. 검증 화면과 합성 예시는 [검증 자료](../../.impeccable/review/cutout/)에 있습니다.

화면은 기존 [디자인 기준](../../DESIGN.md)의 연분홍·흰 표면, 로즈 액션, 공통 버튼·슬라이더와 글자 스타일을 이어 사용합니다. 이번 기능은 장소 상세와 촬영 흐름의 확장이며 디자인 정체성을 바꾸지 않습니다.
